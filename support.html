Support

Need help with the keyboard or dictation? Start with the steps below, or email us and we’ll help you sort it out.

Set up the keyboard

  1. Open Settings › General › Keyboard › Keyboards › Add New Keyboard, then choose Saystitch.
  2. Tap Saystitch in the keyboard list and enable Allow Full Access. Saystitch uses Full Access to share dictation results and settings between the keyboard and app.
  3. In any text field, touch and hold the globe key and select Saystitch. The keyboard includes both a microphone and regular typing keys.

Start your first dictation

When the microphone is off, tap the keyboard microphone, open Saystitch, and tap Start dictation. Follow the on-screen guide to return to the text field, then tap the keyboard microphone again to finish and insert the text. During the optional ready period, the next dictation can start directly from the keyboard.

Check microphone and speech setup

  • Make sure Saystitch has microphone permission in iOS Settings.
  • Choose a supported dictation language and download Apple's on-device speech model if it is available for your device and language. Otherwise, Apple’s speech recognition service may be used.
  • AI writing styles use Apple Intelligence when available; basic cleanup is used when it isn’t.
  • In Saystitch Settings, set Keep mic ready for to Off to end the mic session as soon as dictation finishes.
